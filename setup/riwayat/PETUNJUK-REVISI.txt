PEMASANGAN
1. Unggah hanya app.js dan index.html ke lokasi yang sama di GitHub lalu commit.
2. VPS: cd /var/www/smart-cattle
3. Periksa: git status --short
4. Jika hanya API untracked seperti sebelumnya dan GitHub tidak menambah PHP,
   jalankan: git pull --ff-only
5. Ctrl+F5 di browser, periksa Dashboard dan Lingkungan Kandang.
Jangan menghapus PHP, memakai git reset --hard, atau mengganti seluruh folder VPS.

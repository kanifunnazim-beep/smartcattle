AMBANG SEMENTARA (inklusif jika ditulis >= atau <=)
HR normal 48–84 bpm; Warning >0 sampai <48 atau >84;
Critical >0 sampai <40 atau >=110 bpm mendahului Warning.
Suhu sensor normal 36.7–39.1 C; Warning di luar rentang;
Critical >0 sampai <35 atau >=40 C mendahului Warning.
Status gabungan memakai kondisi terberat dari parameter valid.
Offline/belum ada data terpisah dari kondisi kesehatan terkini.

PENTING: Ini ambang monitoring sementara, bukan diagnosis dan belum divalidasi
untuk sapi Bali. Batas Critical adalah keputusan implementasi sementara,
bukan batas klinis yang dikutip dari referensi. HR 48–84 berasal dari sapi
perah istirahat; suhu 36.7–39.1 adalah suhu REKTAL sapi potong. Sensor di dekat
HR mengukur kondisi lokal; tidak setara otomatis dengan suhu rektal.
Verifikasi dengan alat rujukan dan tenaga veteriner sebelum pemakaian klinis.
Referensi:
https://www.merckvetmanual.com/multimedia/table/resting-heart-rates
https://www.merckvetmanual.com/multimedia/table/normal-rectal-temperature-ranges

PEMASANGAN

2. Unggah tiga file revisi ke folder yang sama di GitHub (jangan folder bertingkat).
3. Di VPS /var/www/smart-cattle: git pull --ff-only.
4. Refresh browser Ctrl+F5. Tidak perlu restart Apache.
5. Pastikan /api/fan, api-test.php dan api-environment.php tetap tersedia.
   File PHP server tidak disertakan/diganti.
6. Periksa fan, data C001–C010, grafik, notifikasi, dan menu Pakan.
Rollback: pulihkan tiga file dari cadangan atau revert commit revisi.

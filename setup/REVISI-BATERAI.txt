PEMASANGAN
1. Backup app.js dan index.html di VPS ke folder /root.
2. Upload app.js, index.html, dan catatan ini ke GitHub sesuai folder.
3. git fetch origin; git status --short; git diff HEAD origin/main --name-status
4. Pastikan hanya perubahan yang dimaksud, lalu git pull --ff-only.
5. Refresh browser Ctrl+F5. C002 harus menampilkan 0% jika data terakhir masih 0.
6. Cek detail sapi, tabel sapi, dan perangkat; sapi tanpa baterai tampil tanda pisah.
